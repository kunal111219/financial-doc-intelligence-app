# Test Documents

Synthetic invoices/contracts are included here directly.

Real 10-K filings are excluded from this repo (large files, publicly
available) — download them yourself from SEC EDGAR:
https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany

This project's test set used: Apple, Microsoft, Walmart, PepsiCo, JPMorgan
(most recent 10-K as of build time). Save as `<company>_10k_fy<year>.pdf`.
